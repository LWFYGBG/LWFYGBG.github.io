# 数学史

数学史是人类思想史中最壮丽的篇章之一。从古埃及的实用算术到当代的抽象理论，数学的发展始终伴随着文明的进步。

## 古代数学

### 古埃及与美索不达米亚（约公元前3000年—前500年）
- 埃及的莫斯科数学纸草书和莱因德纸草书记载了分数、面积计算等问题
- 巴比伦人发展了六十进制计数法，能解二次方程

### 古希腊数学（约前600年—公元300年）
- **泰勒斯**：第一个证明几何定理
- **毕达哥拉斯**：数论与毕达哥拉斯定理
- **欧几里得**：《几何原本》— 公理体系的典范
- **阿基米德**：穷竭法、浮力定律
- **丢番图**：《算术》— 代数的先驱

## 中世纪与文艺复兴

### 东方数学
- 中国：《九章算术》、祖冲之的圆周率计算
- 印度：十进制计数法、零的发明，阿拉伯数字
- 波斯：花拉子密《代数学》— "代数"一词的来源

### 文艺复兴时期
- 三次、四次方程求解（卡尔达诺、费拉里）
- 韦达引入符号代数

## 近代数学（17—18世纪）

- **牛顿与莱布尼茨**：微积分的创立
- **欧拉**：数学史上最多产的数学家，贡献遍及所有分支
- **高斯**："数学王子"，数论、几何、分析的巨擘
- **拉格朗日、拉普拉斯、柯西**：分析学的严格化

## 现代数学（19世纪—20世纪）

### 19世纪
- 非欧几何的发现（罗巴切夫斯基、波尔约、黎曼）
- 群论（伽罗瓦）、集合论（康托尔）
- 分析的严格化（魏尔斯特拉斯、戴德金、康托尔）

### 20世纪及以后
- 希尔伯特的23个问题（1900）
- 哥德尔不完备定理（1931）
- 计算理论的诞生（图灵、丘奇）
- 陈省身、华罗庚等对现代数学的重大贡献

到现在为止，仍然有许多深刻的问题等待新一代数学家去解答。
