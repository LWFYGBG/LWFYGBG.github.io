拓扑学

概述

On this page

拓扑学 ​

拓扑学是研究"连续变换下保持不变的性质"的数学分支，常被称为"橡皮膜上的几何学"——在拉伸、压缩、扭曲（但不撕破或粘合）下保持的性质就是拓扑性质。

核心领域 ​

点集拓扑（一般拓扑） ​

拓扑学的基础，研究拓扑空间、连续映射、紧致性、连通性、分离公理等基本概念。它为整个拓扑学提供了通用的语言框架。

代数拓扑 ​

使用代数工具（群、同调、同伦等）研究拓扑空间。关键概念包括：

  • 基本群 π1(X)：刻画空间中环路的分类
  • 同调群 Hn(X)：度量空间的"洞"的结构
  • 欧拉示性数 χ=V−E+F：多面体拓扑不变量，在多面体上满足 χ=2

欧拉公式是最早的拓扑学发现之一，对凸多面体有：

V−E+F=2

微分拓扑 ​

研究光滑流形上的拓扑性质。一个重要的结论是：在二维球面上，你无法梳理头发使其处处光滑——毛球定理（Hairy Ball Theorem）断言：偶数维球面 S2n 上不存在处处非零的连续切向量场。

几何化猜想 ​

佩雷尔曼（Grigori Perelman）在2003年证明的瑟斯顿几何化猜想（包括庞加莱猜想作为特例）彻底解决了三维流形的分类问题。庞加莱猜想断言：任何单连通的闭三维流形同胚于三维球面 S3。
