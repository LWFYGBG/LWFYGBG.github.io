# 啥也不会怎么办？

这一部分适合毫无数学基础的读者阅读，将从最基本的数数开始，逐步构建数学大厦的地基，使得读者可以阅读进阶内容。

## 内容速览

### [集合](./set)
门前大桥下，游过一群鸭，如何用数学描述“一群”？？

### [自然数：皮亚诺公理](./natural-numbers)
快来快来数一数，二四六七八，如何数数？

### [越来越大的数学世界](./number-systems)
自然数之后有整数、有理数、实数……数学世界不断扩展。本节将沿着数系的扩张之路，看看数学如何从简单计数走向抽象结构。
