# 自然数：皮亚诺公理

## 自然数：天下万物生于有，有生于无

我相信绝大多数读者都会数数这项技能，但是我们暂时先忘记它。

在数学世界，我们刚刚知道了集合的概念，但我们还不能数清集合里有多少东西。

不过我们至少可以找一个开始，即“什么也没有”，这是必然的，使用一个符号表示，叫做 $0$  
在此基础上，可以进行下一步，数量在 $0$ 的基础上增加，增加的大小应当是可以比较的，所以应该有一个最小的增加值，使用 $0++$ 表示，在 $0++$ 的基础上，当然也可以继续增加，也就是 $(0++) ++$  
依次类推，数量应该是如此等量增加的，于是我们就有了如下一列从少到多的数量：  
$0,0++,(0++)++,...$  
但是这样标记太复杂了，我们可以像 $0$ 一样使用符号表示，即：  
$1 := 0{++}$，$2 := (0++)++$...  
其中 $:=$ 的意义是“定义为”，这是我们提到的第一个用于简写数学语言的符号。  
此外，我们所做的操作 $++$ 称为“后继”。  
由于数量是唯一的，所以应该有：如果两个数的后继是一个数，则这两个数也是同一个数。  
经过以上探究，我们成功学会了数数，这样数出来的数字称为自然数，所有的自然数当然构成一个集合，称为自然数集，使用$N$表示。  

## 皮亚诺公理

我们知道，全部的数学都是建立在公理体系之上的，所谓公理，就是一些默认必然成立的结论。  
结合以上讨论，可以总结出五条公理，历史上是皮亚诺最先给出的：  

> **公理 1** $0$ 是一个自然数。  
> **公理 2** 若 $n$ 是自然数，则 $n{++}$ 也是自然数。  
> **公理 3** 若 $n{++} = m{++}$，则 $n = m$。  
> **公理 4** 不存在自然数 $n$ 使得 $n{++} = 0$。  



仅有以上四条公理还不够。考虑一个集合 $A = \{0, 0.5, 1, 1.5, 2, 2.5, \ldots\}$，它满足公理 2.1–2.4，但包含了"自然数"本不该有的 $0.5$。我们需要排除这些多余的元素：

> **公理 5** 设 $P(n)$ 是关于自然数 $n$ 的某个性质。若
> 1. $P(0)$ 为真，且
> 2. 只要 $P(n)$ 为真，$P(n{++})$ 就为真，
>
> 则对一切自然数 $n$，$P(n)$ 均为真。

这就是**数学归纳法**。它只保留那些由 $0$ 出发、反复取后继能到达的数，排除了非自然数。

## 2.2 加法

有了自然数的定义，我们来定义最基础的运算——加法。

> **定义 2.1（加法）** 设 $m, n$ 为自然数。定义它们的和 $m + n$ 如下：
> - $m + 0 := m$
> - $m + (n{++}) := (m + n){++}$

换言之，加 $0$ 不变，加 $n{++}$ 就等于先加 $n$ 再取后继。

**例**：计算 $2 + 1$。
$$
2 + 1 = 2 + (0{++}) = (2 + 0){++} = 2{++} = 3
$$

**例**：计算 $0 + 2$。
$$
0 + 2 = 0 + (1{++}) = (0 + 1){++} = (0 + (0{++})){++} = ((0 + 0){++}){++} = (0{++}){++} = 1{++} = 2
$$

上面的例子似乎暗示 $0 + n = n$ 总是成立，但我们还没有证明它。事实上，从定义出发，$0 + 0 = 0$ 是定义直接给的，但 $0 + 1$ 需要计算一步。我们需要用归纳法来证明这个性质。

> **引理 2.1** 对任意自然数 $n$，$n + 0 = n$。
>
> *证*：由加法定义，$n + 0 = n$，证毕。

> **引理 2.2** 对任意自然数 $n$，$0 + n = n$。
>
> *证*：用归纳法。
> - 归纳基础：$0 + 0 = 0$，成立。
> - 归纳步骤：设 $0 + n = n$，则
>   $$ 0 + (n{++}) = (0 + n){++} = n{++} $$
>   证毕。

> **引理 2.3** 对任意自然数 $n$，$n{++} = n + 1$。
>
> *证*：$n + 1 = n + (0{++}) = (n + 0){++} = n{++}$，证毕。

> **命题 2.1（加法结合律）** 对任意自然数 $a, b, c$，
> $$ (a + b) + c = a + (b + c) $$
>
> *证*：固定 $a, b$，对 $c$ 作归纳。
> - 基础：$c = 0$ 时 $(a + b) + 0 = a + b = a + (b + 0)$。
> - 步骤：设 $(a + b) + c = a + (b + c)$，则
>   $$ (a + b) + (c{++}) = ((a + b) + c){++} = (a + (b + c)){++} = a + ((b + c){++}) = a + (b + (c{++})) $$
>   证毕。

> **命题 2.2（加法交换律）** 对任意自然数 $a, b$，
> $$ a + b = b + a $$
>
> *证*：固定 $b$，对 $a$ 作归纳。
> - 基础：$a = 0$ 时 $0 + b = b + 0$，由引理 2.1 和 2.2 得证。
> - 步骤：设 $a + b = b + a$，则
>   $$ (a{++}) + b = (a + b){++} = (b + a){++} = b + (a{++}) $$
>   证毕。

> **命题 2.3（消去律）** 若 $a + b = a + c$，则 $b = c$。
>
> *证*：对 $a$ 作归纳。
> - 基础：$a = 0$ 时 $0 + b = 0 + c$ 直接给出 $b = c$。
> - 步骤：设 $a + b = a + c \Rightarrow b = c$。若 $(a{++}) + b = (a{++}) + c$，则由加法定义得 $(a + b){++} = (a + c){++}$，由公理 2.3 得 $a + b = a + c$，由归纳假设得 $b = c$。证毕。

## 2.3 乘法

> **定义 2.2（乘法）** 设 $m, n$ 为自然数。定义它们的积 $m \times n$ 如下：
> - $m \times 0 := 0$
> - $m \times (n{++}) := (m \times n) + m$

乘法就是"重复加法"的形式化：$m \times n$ 表示把 $m$ 加 $n$ 次。

> **引理 2.4** 对任意自然数 $n$，$0 \times n = 0$，$n \times 0 = 0$。

> **引理 2.5** 对任意自然数 $n$，$1 \times n = n$，$n \times 1 = n$。

> **命题 2.4（乘法分配律）** 对任意自然数 $a, b, c$，
> $$ a \times (b + c) = a \times b + a \times c $$

> **命题 2.5（乘法结合律）** 对任意自然数 $a, b, c$，
> $$ (a \times b) \times c = a \times (b \times c) $$

> **命题 2.6（乘法交换律）** 对任意自然数 $a, b$，
> $$ a \times b = b \times a $$

以上三个命题均可用归纳法证明，作为练习留给读者。

## 2.4 序

> **定义 2.3（序）** 设 $a, b$ 为自然数。若存在自然数 $c$ 使得 $a + c = b$，则称 $a \leq b$（或 $b \geq a$）。若 $a \leq b$ 且 $a \neq b$，则称 $a < b$。

> **命题 2.7（序的性质）** 对任意自然数 $a, b, c$：
> 1. **自反性**：$a \leq a$
> 2. **传递性**：若 $a \leq b$ 且 $b \leq c$，则 $a \leq c$
> 3. **反对称性**：若 $a \leq b$ 且 $b \leq a$，则 $a = b$
> 4. **保加性**：若 $a \leq b$，则 $a + c \leq b + c$
> 5. **保乘性**：若 $a \leq b$ 且 $c > 0$，则 $a \times c \leq b \times c$
> 6. **全序性**：$a \leq b$ 或 $b \leq a$ 必居其一

> **命题 2.8（良序原理）** 自然数的任何非空子集都有最小元。

良序原理是数学归纳法的重要推论，也是它的一种等价形式。

## 2.5 注记

我们从五条公理出发，定义了加法、乘法、序，并证明了它们的基本性质。每一条定理都严格建立在之前的公理和定理之上——整个算术大厦被归纳法这枚钉子牢牢固定。

这个框架是陶哲轩《实分析》的起点。在后续章节中，自然数将被扩展为整数、有理数、实数，每一步扩张都遵循同样的精神：**用精确的定义代替直观，用证明代替想当然**。
