数学结构 ​

20世纪30年代，法国数学家团体布尔巴基（Nicolas Bourbaki）提出：数学的核心是研究"结构"。他们将各种数学理论归结为少数几种基本结构类型。

三种母结构 ​

布尔巴基认为，所有的数学结构都可以从以下三种基本结构中派生出来：

1. 代数结构 ​

代数结构由一个集合和其上的运算（如加法、乘法）组成。运算是从 An 到 A 的映射。

常见的代数结构包括：

  • 半群：满足结合律的二元运算
  • 群：有单位元和逆元的半群
  • 环：具有加法和乘法的代数结构
  • 域：两种运算都构成交换群的环
  • 向量空间：在域上定义了加法和标量乘法的结构

2. 序结构 ​

序结构由一个集合和其上的偏序关系 ≤ 组成，满足：

  • 自反性：a≤a
  • 反对称性：a≤b 且 b≤a⇒a=b
  • 传递性：a≤b 且 b≤c⇒a≤c

如果任意两个元素都可比较（a≤b 或 b≤a），则称为全序。

3. 拓扑结构 ​

拓扑结构定义了"邻近"和"极限"的概念。一个拓扑空间 (X,T) 是集合 X 和其上的开集族 T，满足：

  • ∅,X∈T
  • 任意开集的并是开集
  • 有限个开集的交是开集

结构主义观点 ​

布尔巴基的数学观对20世纪数学教育产生了深远影响：

数学不是研究对象，而是研究对象之间的关系结构。

例如，"3"这个数本身不是数学研究的对象——重要的是它在自然数系统（一个带有后继运算的代数结构 + 序结构）中的位置和关系。

同构与同态 ​

同态（homomorphism）是保持结构不变的映射：

  • 代数同态：f(a∗b)=f(a)∗f(b)
  • 序同态：a≤b⇒f(a)≤f(b)
  • 连续映射：开集的原像是开集

同构（isomorphism）是可逆的同态。同构的两个对象在结构上被视为"相同"——它们具有相同的结构性质。

范畴论 ​

范畴论是比结构更一般的数学框架，将研究焦点从"集合与元素"转移到"对象与箭头（态射）"：

  • 范畴 C 由对象集合 Ob(C) 和态射集合 Hom(A,B) 组成
  • 态射可复合，复合满足结合律
  • 每个对象有单位态射

例如，集合范畴 Set 以集合为对象、函数为态射；群范畴 Grp 以群为对象、群同态为态射。

尤里卡时刻：范畴论揭示了不同数学分支之间的深层类比——例如，笛卡尔积和自由群都满足"泛性质"（universal property）。
