On this page

数论 ​

数论是研究整数性质的数学分支，被称为"数学的皇后"。它表面简单（只涉及整数），但深处蕴藏着极为深刻和美丽的问题。

核心领域 ​

初等数论 ​

研究整数的基本性质：整除性、最大公因数、最小公倍数、素数分布、同余理论等。欧几里得算法、算术基本定理、中国剩余定理是初等数论的基础。

解析数论 ​

使用分析学的方法研究数论问题。黎曼 ζ 函数是核心工具之一：

ζ(s)=∑n=1∞1ns=∏p 素数11−p−s

黎曼猜想（Riemann Hypothesis）断言 ζ 函数的所有非平凡零点都位于直线 Re(s)=12 上。这是数学中最重要的未解决问题之一。

代数数论 ​

将数论问题放到代数数域的框架中研究。关键概念包括代数整数、理想类群、伽罗瓦表示等。费马大定理的证明（怀尔斯，1994）是代数数论最辉煌的成就之一。
