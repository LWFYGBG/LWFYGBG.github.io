# 概率与统计

概率论研究随机现象的数学规律，统计学则研究如何从数据中推断信息和做出决策。两者互为表里，在现代科学和数据分析中至关重要。

## 概率论

### 基本概念
概率空间由样本空间 $\Omega$、事件域 $\mathcal{F}$ 和概率测度 $P$ 构成。概率测度满足三条公理（科尔莫戈罗夫公理）：

1. **非负性**：$P(A) \geq 0$ 对所有 $A \in \mathcal{F}$
2. **规范性**：$P(\Omega) = 1$
3. **可列可加性**：对互不相容的事件序列 $\{A_i\}$ 有 $P(\bigcup_i A_i) = \sum_i P(A_i)$

### 随机变量与分布
随机变量是从样本空间到实数的函数。重要的分布包括：

- 正态分布：密度函数 $f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$
- 伯努利分布、二项分布、泊松分布
- 指数分布、均匀分布

### 大数定律与中心极限定理
- **大数定律**：样本均值以概率收敛于期望
- **中心极限定理**：独立同分布随机变量之和标准化后依分布收敛于正态分布

$$ \sqrt{n}(\bar{X}_n - \mu) \xrightarrow{d} N(0, \sigma^2) $$

## 统计学

### 描述统计
通过均值、中位数、方差、分位数等统计量以及图表（直方图、箱线图）来概括数据。

### 推断统计
- **参数估计**：点估计（MLE、矩估计）和区间估计
- **假设检验**：$p$ 值、第一类错误、功效
- **贝叶斯统计**：$P(\theta|X) \propto P(X|\theta)P(\theta)$

### 回归分析
线性回归模型 $Y = X\beta + \varepsilon$ 是最基本的统计建模工具。最小二乘估计给出 $\hat{\beta} = (X^TX)^{-1}X^TY$。
