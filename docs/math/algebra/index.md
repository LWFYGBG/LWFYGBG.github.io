# 代数学

代数学是研究代数结构（如群、环、域、模、向量空间等）的数学分支。它起源于对多项式方程求解规律的探索，逐步抽象为研究运算与结构的纯粹理论。

## 核心领域

### [初等代数](./elementary-algebra)
初等代数是代数的入门分支，研究数系（自然数、整数、有理数、实数、复数）的基本性质以及多项式方程的解。它包括一元二次方程求根公式、多项式因式分解、不等式等内容。

### [线性代数](./linear-algebra)
线性代数是研究向量空间和线性变换的数学分支。它是最广泛应用的基础数学工具之一，涉及矩阵论、特征值理论、正交投影等概念。线性代数是现代科学计算的基石。

### [抽象代数](./abstract-algebra)
抽象代数是代数学的"高级"分支，研究群、环、域、模等代数结构的一般性质。其中群论研究对称性，环论研究多项式方程系统，域论为伽罗瓦理论提供框架。

## 核心概念

| 概念 | 描述 | 示例 |
|------|------|------|
| 群 | 带有封闭、结合、单位元、逆元的二元运算 | 整数加法群 $(\mathbb{Z}, +)$ |
| 环 | 具有加法（构成群）和乘法（半群）的代数结构 | 整数环 $(\mathbb{Z}, +, \cdot)$ |
| 域 | 加法构成群、非零元乘法构成群的交换环 | 实数域 $\mathbb{R}$ |
| 向量空间 | 在域上定义了加法和标量乘法的集合 | $\mathbb{R}^n$ |
