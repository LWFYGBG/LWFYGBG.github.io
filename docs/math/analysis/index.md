# 分析学

分析学是数学的核心分支之一，它以极限为基础工具，系统研究函数、连续、微分、积分和级数等概念。分析学的起源可追溯至17世纪牛顿和莱布尼茨创立的微积分，后经柯西、魏尔斯特拉斯等人的严格化工作，发展成为现代数学的基石。

## 入门知识

### [微积分基础](./calculus/)
微积分是分析学中最基础的部分，微分学研究变化率，积分学研究累积总量，微积分基本定理将两者联系起来。

### [实分析](./real-analysis)
实分析严格地建立实数系统上的极限、连续、微分和积分理论。勒贝格积分将黎曼积分推广到更广泛的函数类上，测度论则为概率论提供了严格的数学基础。

### [复分析](./complex-analysis)
复分析研究复变函数的性质。柯西积分公式、留数定理等核心成果使得复分析在数学物理、数论和工程中有极为广泛的应用。

### [泛函分析](./functional-analysis)
泛函分析将分析学的方法应用于无穷维向量空间，希尔伯特空间、巴拿赫空间、算子理论等核心概念在现代数学和量子力学中至关重要。

## 基本思想

分析学的核心是"逼近"的思想：用简单的东西逼近复杂的东西，用有限逼近无限。

- 微分：切线逼近曲线
- 积分：矩形逼近面积
- 级数：多项式逼近函数
- 傅里叶级数：三角函数逼近周期函数
